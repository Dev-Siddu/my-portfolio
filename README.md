# My(Siddarood) Professional Full-Stack Portfolio

A high-performance, responsive portfolio website designed to showcase my expertise in the **.NET Ecosystem**, Frontend Development, and Cloud Architecture.

## 🚀 Key Features
- **Theme Engine:** Integrated "Dark Mode little bit Hacker Mode" and "Visual Studio (.NET) Mode" using CSS Custom Properties and Data Attributes.
- **Dynamic Stats:** Custom JavaScript logic to calculate professional tenure and automation impact metrics in real-time.
- **Responsive Design:** Mobile-first approach using React-Bootstrap and custom CSS3 animations.

## 🛠️ Tech Stack
- **Frontend:** React.js, Bootstrap 5, CSS3 (BEM Methodology)
- **Icons:** Bootstrap Icons

## ⚙️ Logic Highlight
Instead of static text, this portfolio uses an iterative date-diff algorithm to calculate total work experience across multiple roles (Infosys, Caliber), ensuring the data is always accurate to the day.
